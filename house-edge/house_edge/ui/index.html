House Edge

Deal yourself in.

House Edge sits outside your game and changes it while you play: unlimited chips, frozen timers, whatever the game keeps in memory. Single-player only.

Waiting for to start. House Edge will join on its own.
  1. Start the game from Steam.
  2. Pick it from the list below. House Edge remembers it and joins automatically next time.
  3. Use the Value finder to turn any number on screen into a mod.

Turn any number in the game into a mod in about a minute. Open the Value finder, search for a number you can see (like your chips), change it in the game, search again, then add it here.

Value finder

  1. Find a number in the game, like 500 chips.
  2. Type it below and press First scan.
  3. Change it in the game: win, lose or spend some.
  4. Type the new number and press Next scan. Repeat until a few results are left.
  5. Press + Mod on the one that matches.

Health bars and timers are usually decimals. Money and counters are usually whole numbers.

Play fair: House Edge is for single-player and local games. Don't use it online against other people or in games with anti-cheat. It spoils the game for others and can get your account banned.

Mods are saved per game in House Edge's settings folder. Values found by scanning only last until the game closes, unless they live inside the game's files, like GameAssembly.dll+1A2B.
