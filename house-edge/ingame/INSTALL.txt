HOUSE EDGE IN-GAME: mod menu for We're All In
==============================================

EASY INSTALL (double-click)
1. Unzip the download first: right-click it and choose Extract All.
2. Open the new folder and double-click "Install House Edge.exe".
   It finds We're All In by itself (the full game and the demo, in any Steam library),
   picks the 32-bit or 64-bit loader to match, and keeps your pins and settings when updating.
   If it can't find the game, it asks you to drag the game folder into its window.
3. Start the game from Steam. The first start takes a little longer while BepInEx sets itself up.
4. Hold Q + E together in the game. The House Edge menu opens.
Run the installer again any time to update or uninstall.
If Windows shows "Windows protected your PC", choose More info, then Run anyway. The installer is unsigned.
Dropped the whole unzipped folder into the game folder by mistake? Open it and run the installer from there.
It installs into the game folder around it.

MANUAL INSTALL (drop in)
1. In Steam, right-click We're All In (or We're All In Demo) and choose Manage > Browse local files.
   A folder opens with WereAllIn.exe and UnityPlayer.dll in it. For the demo it's called WereAllInDemo.
2. Copy what's INSIDE the unzipped folder into that folder, so these sit right next to WereAllIn.exe:
     winhttp.dll
     doorstop_config.ini
     BepInEx\            (folder)
   Not the unzipped folder itself: the game only finds winhttp.dll when it's right next to WereAllIn.exe.
   The installer and this read-me can come along too. They're harmless.
   If Windows asks, choose "Replace".
3. Start the game from Steam and hold Q + E.
This is for 64-bit games, which is almost all of them. For a 32-bit game, use the installer.
Have the full game and the demo? Install into both. They keep their own pins.

STEAM DECK AND LINUX (PROTON)
Do the install above, then in Steam open the game's Properties and set Launch Options to:
     WINEDLLOVERRIDES="winhttp=n,b" %command%
Without it, Proton skips winhttp.dll and the menu never loads.

USE IT
- Fun: game speed (slow-mo to turbo), gravity (float, moon, upside down), field of view, Party Mode.
- Find values: type what something is called (chips, money, health, lives) or tap a quick word.
- Lots of results? Win or lose some chips, then press Changed (or Went up / Went down).
  Copies the game only shows on screen drop out, and the real value stays. Repeat until one or two are left.
- Change it with +100 and watch the game. If the number on screen changed, press Pin.
- Pinned: Lock keeps a value from changing. All changes every copy, like every enemy's health.
  Pinned values come back by themselves after a level change, a restart or a game update.

ONLINE GAMES
House Edge is for single-player and local play. When you're in an online session with other players,
mods pause by themselves and the menu says so. They turn back on when you leave.
Playing solo or with bots counts as offline.

AFTER A GAME UPDATE
Nothing to do. If the update renamed something you pinned, the pin follows the new name when it can tell
which one it is. If a pin stays on "Not in this part of the game", find the value again and pin it.
If an update ever removes the MonoBleedingEdge folder and adds GameAssembly.dll, the game has switched to a
different engine setup (IL2CPP) that this version of BepInEx can't load. Check back for an update.

CHANGE THE KEYS
After the first launch, open BepInEx\config\houseedge.ingame.cfg and change MenuKeys (for example F1 or Ctrl+M).

IF THE MENU DOESN'T SHOW UP
- Run "Install House Edge.exe". It fixes the usual mistakes: files in a subfolder, or the wrong 32/64-bit loader.
- Check that winhttp.dll is right next to WereAllIn.exe, not in a subfolder.
- Look for BepInEx\LogOutput.log. If it's missing, BepInEx didn't load. Antivirus software sometimes blocks winhttp.dll.
  On Steam Deck or Linux, check the Launch Options line above.
- Search that log for "House Edge" and send it over. It says which version of the game it found and what went wrong.

UNINSTALL
Run "Install House Edge.exe" and type U. Or by hand: delete winhttp.dll, doorstop_config.ini and the BepInEx folder. The game goes back to normal.
